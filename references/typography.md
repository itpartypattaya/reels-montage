# Текст в кадре: фраза одним блоком, переносы, субтитры

Дополняет раздел 3 `SKILL.md` («человек — главный объект, текст — поддержка»). Действует для любого текста в кадре: хук, плашка, перечень, фраза на весь экран, карточка, субтитры.

## Фраза — один блок

Реальная правка по хуку: «межстрочный разрыв сильный, это одна фраза — не разрывай». Подводка висела у верха кадра (y 250), крупное слово — на 300 px ниже, за головой. Глаз читал два разных сообщения.

**Глаз группирует по расстоянию.** Всё, что читается подряд как одна мысль, стоит плотнее, чем расстояние до соседних элементов. Если внутри фразы зазор такой же или больше, чем вокруг неё, фраза распадается.

| Что | Правило |
|---|---|
| Строки одного кегля | шаг строк 1,0–1,1 кегля для заголовка капсом, 1,1–1,2 для плашек (плашки одного кегля — впритык), 1,2–1,3 для субтитров. Шаг задаётся интерлиньяжем, без отступов. Единственное исключение — капс без плашки, обрезанный до высоты заглавной (чтобы зазор к другой части мерился по буквам): шаг добирается отступом |
| Части разного кегля (подводка + крупное слово) | зазор между низом верхней части и верхом букв нижней — **15–25 px** и не больше **0,35 кегля меньшей части**. Меряется по видимым краям (плашки, верх заглавных, высота строчных), а не по рамкам блоков |
| Кеглей в одной фразе | не больше двух. В хуке «подводка + крупное слово» отношение 1,6–2,8 (рабочий пример: 190 / 72). Акцент одного слова внутри строки — ×1,3–1,6 |
| Ось | общая: обе части по центру одной оси **или** по одному левому краю. Мелкая часть не шире крупной больше чем на 15 % |
| Расстояние до соседей | от фразы до другого элемента (лицо, плашка, логотип) — не меньше **2× внутреннего зазора** |
| Движение | части одной фразы в одном слое и одной системе координат: если крупное слово «живёт» в камере, подводка тоже. Появляться могут по словам, но место у них общее с первого кадра |
| Зоны | одна фраза — одна зона кадра («потолок» или «грудь», `faces.md`). Не помещается — сократить текст или уменьшить кегль, а не разнести части по верху и низу |

**Видимый край ≠ рамка строки.** У капса без плашки над и под буквами в строке пустые поля — 0,15–0,25 кегля; строку капса обрезать до высоты заглавной (`lineHeight` ≈ 0,78 у Inter, Manrope, Onest). У строчных видимый верх — высота строчных, над ней ~0,35 кегля пусто: компенсировать отрицательным отступом ~0,2 кегля. Замер: без компенсации «12 дней / до результата» расходились на 38 px вместо 15–25, с ней — 25. Проверять пиксельным замером стоп-кадра, а не по CSS.

**Внутри строки:**
- без выравнивания по ширине и растянутых пробелов; один обычный пробел;
- трекинг крупного капса — минус 1–3 % кегля; капс мелких меток — плюс 0,1–0,2 em; строчные не разрядкой;
- крупное слово капсом по левому краю визуально «отъезжает» вправо на боковой отступ буквы — сдвинуть его влево на 2–4 % кегля.

**Переносы — по смыслу, а не по ширине:**
- короткие слова (в, к, с, у, о, и, а, но, не, на, по, за, от, до, из) не висят в конце строки — склеиваются со следующим неразрывным пробелом; «не» — с глаголом; «ли», «же», «бы» — с предыдущим словом;
- число не отрывается от единицы и слова: «12 дней», «60 %», «3 вопроса»;
- перед тире — неразрывный пробел, тире длинное (—); кавычки «ёлочки»; многоточие одним знаком (…);
- переносов с дефисом нет; строка из одного короткого слова — только если это и есть акцент;
- резать на строки по синтагмам: «Хватит угадывать / ЦИФРЫ», а не «Хватит / угадывать ЦИФРЫ».

Удобно держать в шаблоне Remotion компонент «фраза» (строки с кеглями → зазор считается от кегля) и функцию «склейки» неразрывными пробелами — и брать их для любой плашки. Склейка сохраняет ручные переносы и уже стоящие неразрывные пробелы, « - » превращает в длинное тире, «60 % роста» склеивает так же, как «60% роста». **Ширина — реальным замером шрифтом** (`@remotion/layout-utils`, `measureText`): строка, которая не влезает в ширину кадра с полями, уменьшает кегль — длинное слово или склеенная цепочка не вылезут за кадр. Мерить только после загрузки шрифтов.

**Проверка.** Стоп-кадр с фразой, уменьшенный до 25 %: фраза читается одним пятном. Два пятна с пустотой между ними — зазор велик.

## Субтитры

**Контраст без обводки.** Мягкое затемнение нижней трети градиентом: **15–25 % — только старт**. На светлой одежде, ноутбуке или белой стене его не хватает: в реальных роликах понадобилось 42 % и 60 % (при 34–48 % на белой футболке не читалось); на белых стенах — подложка под субтитры вместо затемнения. Подбирать по стоп-кадру с **самым светлым** фоном за субтитрами.

**Разбивка «Печати» — по фразам, а не по лимиту символов:** граница — конец предложения или пауза; фраза до ~52 символов — целиком, в 2 строки; длиннее — делится по самой заметной паузе ближе к середине; в конце части нет предлога, союза или числа. Лимит 40 символов оставлял хвосты: одно-два слова, оторванные от своей фразы, на отдельной строке.

**Когда скрывать.** Текст в кадре заменяет субтитры: хук с заголовком, плашка-перечень, фраза на весь экран, финальная карточка. Скрытие — на весь интервал элемента плюс 0,05 с, без затухания посреди слова; на интервале скрытия не рисовать ничего, в том числе хвост предыдущей группы.

**Низ блока субтитров — не выше y 1500** (дальше интерфейс). Если две строки от нужного подбородку верха не помещаются, группа идёт **по одной строке подряд**, а верх не поднимается; не влезает и одна — блок поднимается.

**«Плашка» растёт по словам**: место строк рассчитывается заранее по реальной ширине шрифта, непроизнесённые слова не видны, строки не прыгают.

**Распознавание в субтитрах:**
- перерасшифровка тоже путает короткие слова — предлоги («в которой» или «к которой»): спорное слушать, не услышал уверенно — в «что висит» с таймкодом;
- термины бренда проверять отдельно: на ускоренной версии распознаватель слышал «следов» вместо «лидов»;
- буква ё — везде (всё, ещё, поймёте): распознаватель её теряет.

**Цветные эмодзи** (особенно флаги) символом не ставить: Chrome на Windows флаги не рисует — SVG или PNG.
