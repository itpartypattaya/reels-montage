# Внешние источники: стоки, генерация видео, мемы — условия, цены, ключи

Ресерч от 01.10.2026 по документации сервисов. Цены и условия меняются каждые месяцы, поэтому перед первым платным запуском открыть страницу модели или тарифа.

**Все внешние сервисы — необязательные зависимости.** Без них скилл работает: футаж — из проекта и библиотеки, генерация — кодом, мемы — из своей папки и библиотеки.

## Ключи

Ключи берутся из переменных окружения или из файла вне скилла и вне проекта, например `~/.config/reels-montage/keys.env` со строками `ИМЯ=значение`. Ключи не печатаются и не попадают в репозиторий.

| Переменная | Сервис | Для чего |
|---|---|---|
| `PIXABAY_API_KEY` | Pixabay | онлайн-сток по умолчанию |
| `PEXELS_API_KEY` | Pexels | второй сток |
| `MAGNIFIC_API_KEY` (или `FREEPIK_API_KEY`) | Magnific (бывший Freepik, + Videvo) | платный сток с фильтром 9:16 |
| `FAL_KEY` | fal.ai | генерация моделью: Veo / Kling / LTX |
| `GIPHY_API_KEY` | GIPHY | только референсы мемов |
| — | Openverse | CC-картинки, без ключа (анонимно около 100 запросов в день) |

Офлайн-режим (переменная вроде `REELS_OFFLINE=1`) отключает сеть совсем.

## Стоки видео

| Сервис | API и ключ | Вертикаль | Коммерция | Цена |
|---|---|---|---|---|
| **Pixabay** | да, бесплатный ключ | фильтра нет, отбирать по h > w | да, без атрибуции | 0 |
| **Pexels** | да; выдача новых ключей была на паузе (01.10.2026) | `orientation=portrait` | да, без атрибуции | 0 |
| **Magnific** (Freepik, Videvo) | да | `filters[orientation]=vertical`, 9:16, длительность | бесплатный контент — с атрибуцией | кредиты |
| Coverr | да | `is_vertical` в ответе | на бесплатном ключе коммерция запрещена | от $5/мес |
| Mixkit | API нет | только на сайте | да | 0, вручную |
| Vecteezy | да | ? | Free: атрибуция, бюджет проекта ≤ $1000 | $1 за клип |
| Shutterstock / Storyblocks / Getty / Adobe Stock | enterprise или платно; у Shutterstock нет 9:16 | — | да | по договору |

Правила Pexels и Pixabay:
- **нельзя:**
  - продавать клип «как есть»;
  - выкладывать на другие стоки;
  - использовать клипы с узнаваемыми брендами в коммерции;
  - показывать узнаваемых людей в плохом свете;
  - создавать впечатление, что человек одобряет продукт;
  - массово скачивать;
- **Pixabay:** ответы API кэшировать 24 ч, лимит 100 запросов в минуту;
- **Pexels:** 200 запросов в час.

Эндпоинты:
- **Pixabay:** `GET https://pixabay.com/api/videos/?key=…&q=…&video_type=film&per_page=50`. Файл — `hits[].videos.large|medium.url`, длительность — `duration`, автор — `user`, страница — `pageURL`.
- **Pexels:** `GET https://api.pexels.com/v1/videos/search?query=…&orientation=portrait&size=medium`, заголовок `Authorization: <ключ>`. Файл — `videos[].video_files[]`: mp4, h > w, ширина ближе к 1080, поле `link`.

**Абстракция источника.** Провайдер умеет два действия: `search(query) → кандидаты` и `fetch(кандидат) → файл`. Кандидат — `{provider, id, title, url | path, page_url, w, h, dur, size_mb, license, author, score}`. Новый сток подключается одним провайдером. Ошибка провайдера — предупреждение и пустой список.

## Генерация видео моделью

| Модель (через fal.ai) | 9:16 | Ровно 6 с | Стартовый кадр | Без звука | ≈ $ за 6 с |
|---|---|---|---|---|---|
| **Veo 3.1 Fast** | да | да (4/6/8) | да | да | **0,60** — хороший дефолт |
| Kling v3 Standard | да | да (3–15) | да, начало и конец | да | 0,50 |
| Veo 3.1 Lite (720p) | да | да | да | да | 0,18 — дешёвый черновик |
| LTX-2.3 (сразу 1080×1920) | да | да (6/8/10) | да | да | 0,36–0,48 |
| Runway gen4.5 | только 720×1280 | 2–10 | да | звука нет вовсе | 0,72 |
| Luma Ray 3.2 | да | нет: 5 или 10 с | да | — | 0,30 (5 с, 720p) |
| Seedance 2.0 | да | да | да | да | 1,45–1,82; отклоняет кадры с реалистичными лицами |
| Sora 2 | — | — | — | — | **API закрыт OpenAI 24.09.2026** |

**Почему через агрегатор (fal.ai):**
- один ключ на много моделей;
- одна очередь: `POST https://queue.fal.run/<model>` → `status_url` → `response_url` → `video.url`;
- модель меняется настройкой.

У моделей разные поля: картинка — `image_url` или `start_image_url`, длительность — `"6s"` или `6`. Нужна таблица соответствий. Звук выключить `generate_audio: false` и для страховки срезать при подготовке (`-an`).

**Запасной путь** — Gemini API напрямую (Veo). Там звук не отключить, его срезают при подготовке. Veo ставит невидимую метку SynthID.

**Метка ИИ.** Meta требует метку «AI info» для фотореалистичного видео, созданного или изменённого ИИ. По сторонним источникам, с лета 2026 реклама с нераскрытым ИИ отклоняется.

## Мемы онлайн

| Сервис | API | Вшивать в коммерческий ролик |
|---|---|---|
| **Openverse** | да, без ключа, `license_type=commercial` | **да**, с атрибуцией (CC) |
| GIPHY | да, бесплатный beta-ключ | **нет**: контент только для личного некоммерческого использования, файлы нельзя хранить — только референс |
| KLIPY | да | нет, прямо запрещено |
| Tenor | закрыт 30.06.2026 | — |
| Imgflip / memegen.link | генераторы подписей на чужих шаблонах | нет: шаблоны — чужие кадры |
| Know Your Meme, Reddit, 9GAG | API нет или коммерция по договору | нет |

**Openverse:** лицензию проверять по **подробной карточке** картинки перед скачиванием — брать только CC0, PDM, CC BY, CC BY-SA (NC и ND — отказ); сохранять код и версию лицензии, ссылку, автора и атрибуцию. Поиск: `GET https://api.openverse.org/v1/images/?q=…&license_type=commercial&page_size=20` → `results[].{id,title,url,foreign_landing_url,creator,license,license_version,attribution,width,height}`.

**Instagram.** Редактор Reels даёт GIF-стикеры GIPHY. Это легальный способ поставить чужой GIF. Можно ли продвигать такой ролик как рекламу — источники противоречат друг другу, проверить в приложении.

**Права.** Есть прецеденты исков за мемы в коммерции. Кадр из фильма или фото человека в ролике бренда читается как одобрение бренда этим человеком.
