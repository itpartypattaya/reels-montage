# Бренды: сохранённые профили, выбор перед монтажом, новый бренд из минимума

Скилл монтирует ролики любого бренда. Всё, что отличает бренды, лежит в профиле: цвета, шрифты, логотипы, LUT, стили, запреты, кто утверждает, настройки вставок. Конвейер (нарезка, камера, субтитры, мастеринг) у всех брендов один.

## Где лежат

Бренд — это папка `brands/<slug>/` (шаблон — `brands/_template/`):

| Что | Зачем |
|---|---|
| `brand.json` | машинная часть: цвета по ролям, шрифты, логотипы, LUT, стиль и субтитры по умолчанию, запреты, политика мемов, размер мемов, дефолты вставок, кто утверждает, тип аккаунта |
| `rules.md` | правила дизайна словами + журнал правил по правкам |
| `assets/` | логотипы, LUT, файлы шрифтов: бренд самодостаточен и переносится одной папкой |

Бренды можно держать и в папке проекта (`<проект>/brands/`). Тогда проектный профиль перекрывает профиль скилла с тем же `slug`.

**Плейсхолдеры `{{…}}` в SKILL.md** — поля профиля выбранного бренда:

| Плейсхолдер | Поле профиля |
|---|---|
| `{{BRAND}}`, `{{TONE}}`, `{{TAGLINE}}` | `name`, `voice`, `tagline` |
| `{{DARK}}`, `{{ACCENT}}`, `{{LIGHT}}` | `colors.primary`, `colors.accent`, `colors.light` |
| `{{MUTED}}`, `{{MARKER}}`, `{{INK}}` | `colors.extra.muted`, `colors.extra.marker`, `colors.extra.ink` |
| `{{FONT_HEADING}}`, `{{FONT_TEXT}}`, `{{FONT_SERIF}}` | `fonts.heading`, `fonts.body`, `fonts.serif` |
| `{{LOGO_DARK_BG}}`, `{{LOGO_LIGHT_BG}}`, `{{LOGO_MARK}}` | `logos.on_dark`, `logos.on_light`, `logos.mark_on_dark` |
| `{{FORBIDDEN_IMAGES}}`, `{{FORBIDDEN_WORDS}}` | `forbidden_imagery` (+ `_en` для промптов генерации), `forbidden_words` |
| `{{SITE}}`, `{{HANDLE}}`, `{{CODE_WORD}}` | `cta.site`, `cta.handle`, `cta.code_word` |
| `{{APPROVER}}`, `{{ACCOUNT_TYPE}}` | `approver`, `account` |

## Шаг 0: выбрать бренд

1. Перечислить сохранённые бренды. Последние использованные идут первыми (`last_used`).
2. Если бренд ясен из промпта или папки, не спрашивать.
3. Если не ясен — первым вопросом в `AskUserQuestion` шага 0 дать 3 последних бренда. Новый бренд — через «Другое»: название и 1–3 цвета.
4. Записать бренд в `edit/<id>/reel.json`, у профиля обновить `last_used`.
5. Прочитать `rules.md` бренда до графики.

## Новый бренд из минимума

Обязательны только название и цвета. Остальное агент выводит сам и говорит, что подставил:

- **Роли цветов:**
  - `primary` — самый тёмный (относительная яркость < 0,25), иначе почти чёрный `#111418`;
  - `accent` — самый «яркий» из остальных, по насыщенности × яркости;
  - `light` — самый светлый (> 0,75), иначе `#FFFFFF`.
- **Цвет текста на фоне.** Первый из цветов бренда с контрастом ≥ 4,5 по WCAG; свой тёмный цвет предпочтительнее чёрного. Если `accent` на `primary` даёт контраст < 3 — предупредить.
- **Материалы.** Агент ищет их в `<проект>/<slug>-brand/`, `<проект>/brand/` и в указанных папках:
  - логотипы — по `logo`, `mark`, `emblem`, `знак` в имени;
  - шрифты — `.ttf/.otf/.woff2`;
  - LUT — `.cube` или hald `.png`;
  - брендбук — `.pdf`;
  - прошлые ролики.
  Найденное копирует в `assets/`.
- **Шрифты по семьям.** Найденные файлы группировать по семье и весу по имени файла (Thin 100 … Black 900, курсив — Italic/Oblique/`-It`): заголовки — семья с самым жирным начертанием, текст — следующая; курсив — отдельным начертанием. Те же слова — в загрузчике шрифтов шаблона, иначе Light станет 400.
- **Одинаковые имена** — сравнивать по содержимому (хеш): другой файл с тем же именем получает `-2`, уже записанные ассеты не перезаписываются. **Slug** — только латиница, цифры, `-`, `_`; пути с `..` отклонять.
- **Шрифты.** Если своих нет, подставляет Manrope + Inter: у обоих есть кириллица.
- **Правила.** Заводит `rules.md` с основой.

## Логотипы

Файл копируется в `assets/`, его роль записывается в `logos`. Роль определяется по файлу:

| Признак | Роль |
|---|---|
| светлый | `on_dark`: для тёмного фона и поверх видео |
| тёмный | `on_light` |
| почти квадрат (0,75–1,33) или со словом `mark`/`знак`/`emblem` в имени | `mark_*`: компактный знак для угла кадра |

Откуда что берётся в кадре:
- **Угол кадра:** `mark_on_dark` → `on_dark`.
- **Финальная карточка:** `on_dark` → `mark_on_dark`.
- **Логотипа нет:** на карточке набирается название бренда.

Перекрашенный самостоятельно вариант (например белый из тёмного) — только с пометкой в `unverified` и вопросом владельцу бренда.

## Правила по правкам

Правка, которая относится к бренду, а не к одному ролику, дописывается в `rules.md` → «Правила по правкам» с датой. Примеры таких правок: «плашки только слева», «знак не в угол, а в карточку», «акцент только на цифрах». Следующий ролик бренда её уже знает. Правки одного ролика остаются в `edit/<id>/project.md`. Непонятно, к чему относится правка, — спросить одной строкой.

## Стили для любого бренда

| Стиль | Для бренда |
|---|---|
| **«Маркер»** | текст `text_on_accent` на плашке `accent`, плашка прорисовывается слева направо; стиль по умолчанию нового бренда |
| **«Фирменный»** | подложки `primary`, акценты `accent`, шрифты бренда |
| **Минимализм / Editorial / Дерзко** | свои шрифты и раскладка, акцентный цвет стиля заменяется на `accent` бренда |
| **Стекло** | стеклянные плашки `primary` — только для сценок, по явному выбору |

Список допустимых стилей и стиль по умолчанию задаются в `styles`, подача субтитров — в `subtitles_default`.

## В Remotion

Профиль копируется в проект Remotion: JSON в `src/brands/<slug>.json`, логотипы в `public/brands/<slug>/`. Код ролика берёт оттуда:
- цвета — `brand.colors.*`;
- шрифты — загрузчик по имени семейства (`@remotion/google-fonts/<Family>` с `subsets: ["cyrillic","latin"]`, локальные файлы — через `FontFace`);
- логотипы — `staticFile(brand.logos.on_dark)`.

HEX-коды и имена шрифтов в код ролика не вписываются.

## Что ещё зависит от бренда

- **Кто утверждает публикацию** — `approver`.
- **Музыка** — `music_policy`. Бизнес-аккаунту не вшивать без коммерческой лицензии.
- **Мемы** — `memes_policy`. При `strict` берутся только мемы с известными правами. Размер мемов — `meme_size`: спокойному бренду — `s`.
- **Вердикты библиотеки иконок.** «Нельзя» по правам (кадры из фильмов, знаменитости, стоковые люди) действует всегда. «Нельзя» по стилю — только для бренда, к которому относится.
- **Запрещённые образы** — `forbidden_imagery` / `_en`. Действуют на B-roll, промпты генерации и мемы.
- **Дефолты вставок** — `inserts`. Например, `{"use_online_footage": false}` для бренда, чей гайдлайн запрещает сток.
