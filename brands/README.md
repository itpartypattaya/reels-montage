# Бренды

Каждый бренд — отдельная папка `brands/<slug>/`: профиль `brand.json`, правила дизайна `rules.md`, файлы `assets/` (логотипы, LUT, шрифты). Брендов может быть сколько угодно. Перед монтажом агент показывает список и спрашивает, для какого бренда ролик.

Новый бренд:
- скопировать `_template/` в `brands/<slug>/` и заполнить;
- или сказать агенту «новый бренд — название, цвета #…, #…, логотип — файл»: он сам распределит цвета по ролям, проверит контраст, подставит шрифты с кириллицей, скопирует файлы в `assets/` и заведёт `rules.md`.

Подробно — [`references/brands.md`](../references/brands.md).

Папки реальных брендов в публичный репозиторий не кладутся: в них логотипы, контакты и правила конкретных клиентов.
