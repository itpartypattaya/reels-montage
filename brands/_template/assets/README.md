# Файлы бренда

Сюда кладутся файлы бренда: логотипы (PNG с прозрачностью или SVG), LUT (hald `.png` для ffmpeg и `.cube` для CapCut), файлы шрифтов (`.ttf`/`.otf`/`.woff2`), если шрифта нет в Google Fonts. Пути в `brand.json` пишутся относительно папки бренда: `assets/logo-white.png`.

Роли логотипов:
- `on_dark` — светлый логотип для тёмного фона и поверх видео;
- `on_light` — тёмный логотип для светлого фона;
- `mark_on_dark` / `mark_on_light` — компактный знак для угла кадра.

Агент может определить роль сам: по средней яркости непрозрачных пикселей (светлый → `on_dark`) и пропорциям (почти квадрат или слово `mark` / `знак` / `emblem` в имени → `mark_*`).
